# NeuroAdvancements

Phase 1: homepage and landing experience. Next.js (App Router), TypeScript, Tailwind CSS v4, Three.js through React Three Fiber and Drei.

## Run

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run typecheck
```

Set `NEXT_PUBLIC_SITE_URL` in production so social tags resolve to absolute URLs.

## The 3D brain

`public/models/brain.glb` is generated by `npm run build:brain` from:

- **Geometry:** FreeSurfer `fsaverage6` pial surface, 40,962 vertices per hemisphere (Fischl et al. 1999), fetched from TemplateFlow (`tpl-fsaverage`, density 41k).
- **Lobes:** the Desikan Killiany atlas (Desikan et al. 2006), grouped into frontal, parietal, temporal, and occipital lobes with FreeSurfer's standard lobe mapping. Membership is baked into each vertex, so a highlight cannot land on the wrong cortex.
- **Shading:** FreeSurfer sulcal depth, baked per vertex, darkens the sulci.

The result is 81,924 vertices and 163,840 triangles in a 1.2 MB meshopt compressed file.

Limits to know about:

- It is an **average cortical surface**, not an individual brain. The cerebellum, brainstem, and subcortical structures are not included. The page says so beside the final chapter.
- Cingulate and insular cortex are not assigned to any of the four lobes and are never highlighted.
- **Licence:** fsaverage and the atlas are distributed under the FreeSurfer Software License. Review its terms and attribution requirements before a commercial launch.

### How the scroll story works

- Four chapters across seven beats: cover, overview, frontal, temporal, parietal, occipital, complete.
- Each beat is a shot (camera orientation, distance, framing, focus, emphasis, callouts, tone) in `lib/content/brain-chapters.ts`.
- One GSAP timeline, scrubbed by ScrollTrigger, tweens a single shot object. The canvas reads it once per frame.
- Pinned chapters use CSS sticky. Nothing is pinned with JavaScript.
- Callouts project real surface anchors (`lib/content/brain-anchors.json`) through the live camera.
- The brain is a custom shader with paper and night presets, plus a decorative activity layer.
- Rendering pauses when the story leaves the viewport. Pixel ratio is capped at 1.75.
- Reduced motion keeps one orientation and changes only emphasis and labels. Without WebGL a still is shown.
- Preview either with `?motion=reduce` or `?webgl=off`.

Details: `docs/stage-c-brain.md` and `docs/stage-d-story.md`.

## Design system

Follows the supplied landing page design skill, with brand colours from the logo.

- **Type:** Manrope only. Every text element uses a named style (`heading-1` to `caption-5`) defined in `app/globals.css`.
- **Spacing:** 0, 2, 4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96 px.
- **Colour (revision 2):** paper `#F7F8F6`, surface `#E9EDF0`, ink `#172A3E`, mist `#9EAEBB`, night `#101A26`, accent `#E47B36`. Primary buttons are ink. Orange is reserved for anatomy and single points of emphasis.
- **Navigation:** translucent glass that thickens to frosted glass over dark sections, because the logo is never recoloured.
- **Motion:** `cubic-bezier(0.22, 1, 0.36, 1)`, transform and opacity only, reveals through IntersectionObserver.
- **Backgrounds:** flat. The only gradient is the hero heading text.

Deviations from the skill, made because the brief overrides it: dark sections use brand navy rather than the skill's neutral dark palette, and GSAP was left out because the story timeline is a small pure function and did not need the dependency.

See `docs/redesign-audit.md` for the audit behind revision 2 and the staged redesign plan.

## Verified and not verified

Checked in a browser at 1440, 768, and 375 px wide: all six story stops, lobe highlights against anatomy, navigation and mobile menu, every section, form validation and submission, the 404 and legal pages, no horizontal overflow. `npm run build` and `npm run typecheck` pass.

Not yet checked: reduced motion in a real browser setting, the WebGL fallback on a device without WebGL, a screen reader pass, performance on low end phones, and Lighthouse scores.
